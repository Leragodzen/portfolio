# Сайт-портфолио Валерии Левановой

Одна страница для холодной рассылки и фриланс-чатов: работы, сроки, цены, вопросы.
Чистый HTML/CSS/JS, без сборщиков. Публикуется на GitHub Pages.

## Файлы

```
index.html            вся главная страница
privacy.html          политика конфиденциальности
assets/style.css      стили
assets/app.js         липкая кнопка внизу экрана — весь скрипт
assets/works/*.jpg    скриншоты клиентских сайтов, 390px-вьюпорт
assets/og.jpg         картинка превью для мессенджеров
assets/valeria.jpg    фото в блоке «обо мне»
assets/fonts/         Unbounded и Onest, кириллица и латиница
ЧТО ЗАПОЛНИТЬ.md      что осталось подставить перед рассылкой
```

## Публикация

Двойной клик по `Опубликовать портфолио.command` на Рабочем столе.

## Как обновить скриншоты работ

Скриншоты сняты в настоящем мобильном вьюпорте 390×844 — через страницу-обёртку
с iframe, иначе headless-браузер верстает шире и текст обрезается.
Анимации входа отключались вставкой стиля в локальную копию сайта.

## Цвета и шрифты

| | |
|---|---|
| бумага | `#F4F2ED` |
| чернила | `#14110F` |
| пламя (единственный акцент) | `#E8410F` |
| приглушённый текст | `#6E6862` |
| заголовки | Unbounded 700/800 |
| текст | Onest 400/500/700 |

Ни один клиентский сайт Валерии этих шрифтов не использует — портфолио
намеренно не похоже ни на одну из её работ.

## Правки

После правки `style.css` или `app.js` поднять `?v=` в `index.html`
и `privacy.html`, иначе у людей останется старая версия из кеша.
